# BikePark Metro Manila — Expanded Directory MVP

This build expands the seed directory using public listings.

## Data included
- Bike parking facilities identified from ParkinganPH's bicycle-accepting parking directory, restricted to Metro Manila entries where the listing provides a Metro Manila location.
- Bicycle shops, retailers, repair shops and rental providers compiled from Cycling Matters, National Bicycle Organization registration-centre listings, Race Pace retail partners, Java Bikes dealer directory, VOOK dealer network, Dan's Bike Shop official store directory and other public directory listings.
- Unknown parking occupancy remains unknown until reported. Never interpret a listing as proof of a currently free slot.
- Some shop directory leads do not publish a precise street address. These are retained as searchable listings but intentionally are not shown as precise map pins until the address is confirmed.

## Limitations
- This is still a front-end prototype. User additions and parking reports are stored only in the current browser.
- The app is not connected to a shared live database or official inventory feed.
- Parking fees, operating hours, store addresses and contact numbers may change; confirm with the facility or shop before visiting.
- Public directory entries can be outdated, duplicated or missing. This is a broad starter directory, not a claim that every Metro Manila bicycle shop or parking facility has been captured.
- Map geocoding uses public Nominatim and may produce approximate pins for incomplete addresses.
